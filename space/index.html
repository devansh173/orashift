Limitations

  • On an unseen construct variant the fine-tune is no better than the base model, and on SYSDATE it is far worse (2/26 against 23/26) because it echoes unfamiliar input unchanged.
  • The data is synthetic and template-generated, so it is more uniform than real-world SQL.
  • This page cannot execute anything. Every accuracy figure comes from the offline evaluation.
